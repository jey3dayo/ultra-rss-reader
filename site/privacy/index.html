Ultra RSS Reader の privacy 概要

このページは、Ultra RSS Reader の公開ソースにある privacy / feed content policy の要点を、 利用者向けに簡潔にまとめたものです。

This page summarizes the current privacy and feed content policy based on the public source of Ultra RSS Reader.

Support support@jey3dayo.net

保存されるデータ

現在の公開情報から確認できる保存先と扱いをまとめています。

These are the storage behaviors that can be confirmed from the current public source.

  • 認証情報

    FreshRSS の password / token は SQLite ではなく OS keyring に保存されます。

    FreshRSS passwords and tokens are stored in the OS keyring, not in SQLite.

  • ローカルデータ

    フィードデータや記事データなど、アプリが扱うデータは SQLite ベースで保持されます。

    App data such as feed and article data is stored through an embedded SQLite database.

  • 記事本文

    Reader 表示では Rust 側で sanitization 済みの HTML を利用します。

    Reader mode uses HTML that has already been sanitized on the Rust side.

通信について

Reader mode と Web Preview の挙動は privacy 上まったく同じではありません。

Reader mode and Web Preview do not have identical privacy behavior.

  • Reader mode

    sanitized article を開いても、publisher 管理下の remote images を読み込む場合があります。

    Even in Reader mode, opening a sanitized article may still load remote images from publisher-controlled hosts.

  • Web Preview

    Web Preview は embedded browser として扱われ、publisher のページを開く操作に近い前提です。

    Web Preview should be treated like visiting the publisher page in an embedded browser.

  • 通信上の露出

    remote media request により、IP address、user agent、timing などが第三者ホストに見える可能性があります。

    Remote media requests may expose your IP address, user agent, and timing information to third-party hosts.

現在の policy

利用前に知っておいてほしい、現在の前提を明示します。

These are the current privacy assumptions users should know today.

  • 現在の方針

    Ultra RSS Reader は現時点で compatibility-first の feed content policy を採っています。

    Ultra RSS Reader currently follows a compatibility-first policy for feed content.

  • 守っていること

    app scripts は 'self' のまま維持し、Reader の HTML は sanitized content を前提にしています。

    App scripts remain locked to 'self', and Reader HTML continues to come from sanitized content.

  • 約束していないこと

    記事を開いても third-party request が一切発生しない、という保証は現在の挙動ではしていません。

    The app does not currently promise that opening an article avoids all third-party requests.

今後の方向性

privacy を強化する場合も、互換性を見ながら段階的に進める方針です。

Future privacy changes are expected to be introduced gradually with compatibility in mind.

  • 一括遮断はしない

    remote images や frames を即座に全面遮断すると、readability や preview compatibility を大きく損なう可能性があります。

    The project is intentionally avoiding an immediate blanket block on remote images and frames.

  • 段階的な強化

    privacy hardening は incremental に進める方針で、Reader と Web Preview を同じスイッチで扱わない方向が示されています。

    Future privacy hardening is expected to be incremental, with Reader mode and Web Preview handled separately.

  • 変更前の確認

    privacy policy を厳しくする変更は、Reader mode、preview mode、packaged builds での検証が前提です。

    Any tighter privacy behavior should be verified in Reader mode, preview mode, and packaged builds first.
