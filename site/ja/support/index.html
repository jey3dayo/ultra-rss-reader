Ultra RSS Reader サポート

Ultra RSS Reader は、ローカル RSS/Atom フィードと FreshRSS に対応したデスクトップ向け RSS リーダーです。 お困りのことがあればメールでお問い合わせください。日本語を中心に、英語でのお問い合わせにも対応しています。

お問い合わせ時に添えていただきたい情報

最初のメールに以下の情報をご記載いただくと、原因の切り分けがスムーズになります。

  • 環境情報

    アプリのバージョン、ご利用の OS、入手元（GitHub Releases / Microsoft Store など）をお知らせください。

  • アカウント構成

    ローカル RSS/Atom フィードか FreshRSS か、どのアカウントで発生したかを教えてください。

  • 発生した現象

    行おうとした操作、実際に起きたこと、同じ手順で再現するかどうかをお書きください。

  • 添付資料（任意）

    スクリーンショット、表示されたエラーメッセージ、共有可能な範囲のログがあると調査に役立ちます。

お問い合わせ前の確認事項

よくあるトラブルは、以下の確認で解決または原因の切り分けができる場合があります。

  • FreshRSS への接続

    サーバー URL、ユーザー名、FreshRSS 側で設定した API パスワードに誤りがないかご確認ください。

  • フィードの追加

    入力した URL が http:// または https:// から始まる完全な URL か、通常のブラウザで開けるかをご確認ください。

  • Webプレビュー

    一部の Web ページはアプリ内での埋め込み表示に対応していません。再試行するか、外部ブラウザで開いてご確認ください。

  • ログの確認

    原因調査が必要な場合は、環境設定 > データ > ログフォルダを開く からログファイルを確認できます。

よくある質問

Ultra RSS Reader の基本機能や操作について、よく寄せられる質問をまとめました。

  • どのようなアプリですか？

    3ペイン UI、オフライン全文検索、キーボードショートカット、OPML エクスポートを備えたデスクトップ向け RSS リーダーです。

  • どのアカウント種別に対応していますか？

    ローカル RSS/Atom フィードと FreshRSS（Google Reader API）に対応しています。

  • 購読一覧をバックアップできますか？

    はい。アカウント設定から OPML 形式でエクスポートできるため、購読リストの控えを残したり他アプリへ移行したりできます。

  • Webプレビューが開けないときはどうすればよいですか？

    配信元の仕様により、アプリ内での埋め込み表示に対応していないページがあります。エラーが出た場合は再試行するか、外部ブラウザで開く操作をご利用ください。
