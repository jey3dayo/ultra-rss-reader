Ultra RSS Reader のサポート

Ultra RSS Reader は、Local RSS/Atom フィードと FreshRSS に対応したデスクトップ向け RSS リーダーです。 困ったときはメールでご連絡ください。サポート窓口はメール中心で、日本語中心ですが英語でも受け付けます。

このページで案内すること

公開ソースから確認できた範囲で、サポート初版に必要な要点をまとめています。

  • 対応アカウント

    Local RSS/Atom フィードと FreshRSS をサポートしています。

  • よくある相談

    同期、フィード追加、Web Preview、ログ確認まわりの問い合わせを想定しています。

  • 英語対応

    日本語中心ですが、英語でのお問い合わせも受け付けています。

問い合わせ時にあると助かる情報

最初のメールに少し情報があるだけで、往復を減らしやすくなります。

  • アプリ情報

    アプリのバージョン、OS、入手元が分かると切り分けが早くなります。

  • 利用中の設定

    ローカルフィードか FreshRSS か、どのアカウントで起きたかを書いてください。

  • 症状の説明

    何をしようとして、何が起きたか、再現するかどうかを教えてください。

  • 添付すると助かるもの

    スクリーンショット、表示されたメッセージ、共有しやすい範囲のログがあると助かります。

まず確認してほしいこと

よくあるパターンは、いくつかの軽い確認で切り分けできます。

  • FreshRSS 接続

    サーバー URL、ユーザー名、FreshRSS 側の API パスワードを確認してください。

  • フィード追加

    フィード URL またはサイト URL が http(s) の完全な URL か、ブラウザで開けるかを確認してください。

  • Web Preview

    一部のページはアプリ内表示に対応しません。再試行するか、外部ブラウザで開いて確認してください。

  • ログ確認

    必要に応じて Settings > Data Management > Open Log Directory からログを開いてください。

よくある質問

アプリのリポジトリの README・設定文言・ランブックから、公開ページ向けに整理した初稿です。

  • どんなアプリですか

    Ultra RSS Reader はデスクトップ向けの RSS リーダーで、3ペイン UI、全文検索、ショートカット、OPML エクスポートに対応しています。

  • どのアカウント種類をサポートしていますか

    公開ソースから確認できる範囲では Local RSS/Atom feeds と FreshRSS がサポート対象です。

  • 購読一覧をバックアップできますか

    アカウント設定から OPML をエクスポートできます。購読一覧の控えを取りたいときに使えます。

  • Web Preview が開けないときは

    アプリ内表示に向かないページがあります。エラー時は再試行するか、外部ブラウザへの導線を使ってください。

プライバシーとデータ

ここではサポートに必要な要点だけを案内します。より詳しい要約はプライバシーページを参照してください。

認証情報

FreshRSS のパスワード / トークンは SQLite ではなく OS のキーリングに保存されます。

記事本文

Reader 表示の HTML はサニタイズ済みの内容を使います。

通信上の注意

Reader のリモート画像や Web Preview は、配信元側ホストへの通信を発生させる場合があります。

プライバシーに関する個別の質問は、プライバシーページ を確認したうえで、 必要なら support@jey3dayo.net までご連絡ください。
