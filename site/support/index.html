Ultra RSS Reader Support

Ultra RSS Reader is a desktop-first RSS reader for Local RSS/Atom feeds and FreshRSS. If you need help, please contact us by email. Support is email-first; Japanese is primary, but English is welcome.

What to include when you contact us

A little context in the first email helps shorten the back-and-forth.

  • App information

    Please include the app version, OS, and where you got the app if possible.

  • Your setup

    Tell us whether the issue happened with Local RSS/Atom feeds or FreshRSS, and which account was affected.

  • Description of the issue

    Explain what you tried to do, what happened, and whether it is reproducible.

  • Helpful attachments

    Screenshots, visible error messages, and shareable logs are especially helpful.

Quick checks to try first

These quick checks often help narrow the issue before you contact support.

  • FreshRSS connection

    Check the server URL, username, and the FreshRSS API password first.

  • Adding a feed

    Make sure the feed URL or site URL is a full http(s) URL and opens in a browser.

  • Web Preview

    Some pages cannot be shown in the in-app view. Retry once or open them in your external browser.

  • Checking logs

    If needed, open logs from Settings > Data > Open log directory.

FAQ

Answers to common questions about Ultra RSS Reader.

  • What is this app?

    Ultra RSS Reader is a desktop-first RSS reader with a three-pane UI, offline full-text search, keyboard shortcuts, and OPML export.

  • Which account types are supported?

    Local RSS/Atom feeds and FreshRSS (Google Reader API) are supported.

  • Can I back up my subscriptions?

    Yes. You can export OPML from account settings to back up your subscriptions.

  • What if Web Preview will not open?

    Some pages are not compatible with Web Preview. Retry or open the page in your external browser.

Privacy and data

Only the key privacy and data notes are summarized here. See the privacy page for a more focused summary.

Credentials

FreshRSS passwords and tokens are stored in the OS keyring, not in SQLite.

Article content

Reader mode uses sanitized HTML content.

Network note

Remote images in Reader mode and Web Preview may still contact publisher-controlled hosts.

If you have a privacy-specific question, please check the privacy page first and, if needed, contact support@jey3dayo.net.
