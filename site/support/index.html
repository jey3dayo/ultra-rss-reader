Ultra RSS Reader のサポート

Ultra RSS Reader は、Local RSS/Atom feeds と FreshRSS に対応した desktop-first RSS reader です。 困ったときはメールでご連絡ください。サポート窓口は email-first で、日本語中心ですが英語でも受け付けます。

Need help with Ultra RSS Reader? Please contact us by email. Japanese is primary, but English is welcome.

このページで案内すること

公開ソースから確認できた範囲で、support 初版に必要な要点をまとめています。

This page covers the first public support draft based on source-backed information.

  • 対応アカウント

    Local RSS/Atom feeds と FreshRSS をサポートしています。

    Supports Local RSS/Atom feeds and FreshRSS.

  • よくある相談

    同期、フィード追加、Web Preview、ログ確認まわりの問い合わせを想定しています。

    Common topics include sync issues, adding feeds, Web Preview, and troubleshooting with logs.

  • 英語対応

    日本語中心ですが、English inquiries are also welcome.

    Japanese is the primary language here, but English inquiries are welcome too.

問い合わせ時にあると助かる情報

最初のメールに少し情報があるだけで、往復を減らしやすくなります。

A little context in the first email helps shorten the back-and-forth.

  • アプリ情報

    アプリのバージョン、OS、入手元が分かると切り分けが早くなります。

    Please include the app version, OS, and where you got the app if possible.

  • 利用中の設定

    Local feeds か FreshRSS か、どのアカウントで起きたかを書いてください。

    Tell us whether the issue happened with Local feeds or FreshRSS, and which account was affected.

  • 症状の説明

    何をしようとして、何が起きたか、再現するかどうかを教えてください。

    Explain what you tried to do, what happened, and whether it is reproducible.

  • 添付すると助かるもの

    スクリーンショット、表示されたメッセージ、共有しやすい範囲のログがあると助かります。

    Screenshots, visible error messages, and shareable logs are especially helpful.

まず確認してほしいこと

よくあるパターンは、いくつかの軽い確認で切り分けできます。

These quick checks often help narrow the issue before you contact support.

  • FreshRSS 接続

    Server URL、ユーザー名、FreshRSS 側の API password を確認してください。

    Check the server URL, username, and the FreshRSS API password first.

  • フィード追加

    Feed URL または Site URL が http(s) の完全な URL か、ブラウザで開けるかを確認してください。

    Make sure the feed URL or site URL is a full http(s) URL and opens in a browser.

  • Web Preview

    一部のページはアプリ内表示に対応しません。再試行するか、外部ブラウザで開いて確認してください。

    Some pages cannot be shown in the in-app view. Retry once or open them in your external browser.

  • ログ確認

    必要に応じて Settings > Data Management > Open Log Directory からログを開いてください。

    If needed, open logs from Settings > Data Management > Open Log Directory.

FAQ 候補

アプリ repo の README・設定文言・runbook から、公開ページ向けに整理した初稿です。

These FAQ entries are adapted from the app repository, settings copy, and runbook.

  • どんなアプリですか

    Ultra RSS Reader は desktop-first の RSS reader で、3 ペイン UI、全文検索、ショートカット、OPML export に対応しています。

    Ultra RSS Reader is a desktop-first RSS reader with a three-pane UI, full-text search, shortcuts, and OPML export.

  • どのアカウント種類をサポートしていますか

    公開ソースから確認できる範囲では Local RSS/Atom feeds と FreshRSS がサポート対象です。

    Based on the public source, supported account types are Local RSS/Atom feeds and FreshRSS.

  • 購読一覧をバックアップできますか

    アカウント設定から OPML を export できます。購読一覧の控えを取りたいときに使えます。

    Yes. You can export OPML from account settings to back up your subscriptions.

  • Web Preview が開けないときは

    アプリ内表示に向かないページがあります。エラー時は再試行するか、外部ブラウザ導線を使ってください。

    Some pages are not compatible with Web Preview. Retry or use the external browser route.

プライバシーとデータ

ここでは support に必要な要点だけを案内します。より詳しい要約は privacy page を参照してください。

Only the key privacy and data notes are summarized here. See the privacy page for a more focused summary.

認証情報

FreshRSS の password / token は SQLite ではなく OS keyring に保存されます。

FreshRSS passwords and tokens are stored in the OS keyring, not in SQLite.

記事本文

Reader 表示の HTML は sanitization 済みの内容を使います。

Reader mode uses sanitized HTML content.

通信上の注意

Reader の remote images や Web Preview は、publisher 側ホストへの通信を発生させる場合があります。

Remote images in Reader mode and Web Preview may still contact publisher-controlled hosts.
